// Fairness Engine

No more "why does he always get the good runs?"

The most politically charged part of dispatching is run fairness. Pedal to the Metal tracks it automatically so you don't have to referee.

⚙ Fairness Engine — Active Monitoring
  • Zone rotation algorithm — even distribution across all active drivers
  • Load count delta tracking — flag any driver more than 20% above or below fleet average
  • Scrap run fairness — separate tracking so "the bad runs" don't stack up on one driver
  • Bridgeport haul queue — premium runs assigned by rotation, not favoritism
  • POD confirmation tracking — accountability for every load, every driver
  • Burnout detection flag — automatic alert when one driver is absorbing too much
  • Weekly fairness report — show drivers the data, kill the drama
  • Override log — when you have to break rotation, the reason is recorded
